# Microsoft Aptos Fonts (Instacertify print)

These TrueType files are from the official [Microsoft Aptos Fonts](https://www.microsoft.com/en-us/download/details.aspx?id=106087) package, for local installation so Instacertify quotation/invoice print (Chrome PDF) can use Aptos Display + Aptos.

See `Microsoft Aptos Fonts EULA.rtf` in this folder. Do not redistribute outside licensed Instacertify deployments.
